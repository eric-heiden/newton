Add `newton.utils.BatchRollout` for batched evaluation: it builds a model with many copies of one world (from a `ModelBuilder` or a script's `build_model()`), the solver, and the collision pipeline once; starts every world from the model, a saved state, or one world of another model with the same layout; runs CUDA-graph-captured frames with per-world control schedules and records named probes as `[T, world, ...]` arrays without per-step host synchronization. `BatchRollout.evaluate()` runs candidates x scenarios with user-written setup, score, and pass functions, runs cases that set solver-shared values or different builds in separate models and says why, and returns a table, a per-candidate summary, and `compare()` diffs against earlier results.
