Add `Model.find_bodies()`, `Model.find_shapes()`, `Model.find_joints()`, `Model.find_joint_dofs()`, and `Model.find_joint_coords()`, which return the model indices that label patterns select (by full label or last path component) in one world or in every world, and add `SolverMuJoCo.newton_body_to_mjc_body` and `SolverMuJoCo.newton_dof_to_mjc_dof`, which map Newton bodies and DOFs to compiled MuJoCo ids. `SolverMuJoCo.newton_shape_to_mjc_geom` is now available in every contact mode.
