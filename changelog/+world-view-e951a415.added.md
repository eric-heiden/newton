Add `newton.selection.WorldView` for per-world access to model, state, and control attributes selected by label pattern: `get_attribute()` and `set_attribute()` read and write values of shape `[world, row, ...]` for bodies, shapes (including static shapes of a world), joints, DOFs, coordinates, articulations, particles, per-world values such as `gravity`, and custom frequencies such as `mujoco:actuator`; `copy_state()` copies the state of one world, or of a single-world model with the same layout, into many worlds. Model edits keep inverse masses, inverse inertias, and shape collision radii consistent and return the `ModelFlags` to notify; with a solver, `set_attribute()` checks and notifies it.
